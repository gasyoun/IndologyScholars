# Голосование по докладам — инструкция по тестированию

## Как работает кнопка «Отправить голосование»

Кнопка делает три вещи:

1. Проверяет, что email студента заполнен.
2. Копирует JSON-выгрузку отметок в буфер обмена.
3. Открывает форму голосования в новой вкладке.

Данные никуда не летят автоматически — студент сам вставляет JSON в поле формы.

---

## Шаг 0. Убедитесь, что форма настроена

Откройте форму как обычный пользователь:
`https://forms.yandex.ru/u/6a28f0e995add5b922d0f14c`

Форма должна содержать:
- Поле **Email** (обязательное) — «Email заполняющего»
- **Длинное текстовое поле** (обязательное) — «JSON выгрузки»

Если форма открывает страницу входа или возвращает 404 — студент не сможет её заполнить. Нужно исправить до публикации: в редакторе формы → Настройки → Доступ → «Любой может заполнить».

---

## Полный алгоритм тестирования

**1. Откройте страницу голосования.**

Через локальный сервер или на задеплоенном сайте.

> Через `file://` копирование в буфер не работает — браузерное ограничение.
> Локальный сервер: `python -m http.server 8000`, затем `http://localhost:8000/voting.html`

**2. Отметьте несколько докладов.**

Поставьте галочки «Слушал(а)» и «Понравилось» у 2–3 докладов. Добавьте тестовый комментарий.

**3. Заполните блок «Кто вы».**

Email — обязательный. Без него кнопка не сработает.

**4. Нажмите «Отправить голосование».**

Ожидаемый результат:
- Статус: `JSON скопирован и открыта форма голосования. Вставьте его в поле «JSON выгрузки» и отправьте.`
- Открывается новая вкладка с формой.

Если статус: `Не удалось скопировать JSON` — вы работаете через `file://`.

**5. В открывшейся форме вставьте JSON (`Ctrl+V`) в поле «JSON выгрузки».**

Текст начинается с `[{` — это массив объектов. Убедитесь, что вставился полностью.

**6. Заполните Email в форме и отправьте.**

**7. Проверьте ответы как администратор.**

Откройте `https://forms.yandex.ru/admin/` → найдите форму → «Ответы». Убедитесь, что строка появилась и поле «JSON выгрузки» содержит корректный JSON.

**8. Проверьте обработку ответов.**

Скачайте ответы из Яндекс Формы в CSV и запустите:

```
python tools/merge_votes.py responses.csv --json-column "JSON выгрузки"
```

Результат появится в `analytics_output/votes/`: `votes_by_talk.csv` и `votes_by_respondent.csv`.

## Возможные проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Форма открывает страницу входа Яндекса | Форма закрыта | Настройки → Доступ → «Любой может заполнить» |
| Форма 404 | Неверный ID в URL | Перепроверить ссылку в админке формы |
| JSON не скопировался | Открыто через `file://` | Использовать `python -m http.server 8000` |
| Поля «JSON выгрузки» нет | Форма не настроена | Добавить длинное текстовое поле с таким названием |
| `merge_votes.py` не находит колонку | Название колонки в CSV не совпадает | Проверить точное название через `--json-column "..."` |
