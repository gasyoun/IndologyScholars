Методика

Пол выводится автоматически из русскоязычного имени (однозначное личное имя, затем отчество, затем склонение фамилии; функция classify_gender в publication_helpers.py). Это вероятностная атрибуция, а не самоидентификация. Имена, не позволяющие надёжного вывода, учитываются отдельной категорией «не определён» и не исключаются из знаменателей. Протокол ручной валидации и измеренная доля ошибок: tools/validate_gender_inference.py; порядок исправления и возражений — в политике персональных данных.

Интервалы доли женщин по годам: cluster_robust_proportion_interval (sandwich SE по кластерам-учёным, поправка G/(G−1); при одном кластере — fallback на Wilson). Точечная оценка остаётся долей участий; меняется только ширина ДИ, чтобы не завышать точность при повторных выступлениях одного докладчика.
