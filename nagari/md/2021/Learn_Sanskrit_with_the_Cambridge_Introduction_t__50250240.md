Отрывок из недавнего обсуждения:



For causatives we're looking to create a "heavy" syllable in the root (see 

chapter 2A). As a quick sparknotes recap, a syllable is “heavy” if it 

contains a long vowel or if the vowel is is followed by more than one 

consonant.

So, because in दर्शयति the vowel in our root syllable is followed by two 

consonants (r & ś), there’s no need for us to lengthen the vowel, the 

syllable is already heavy. Whereas with भृ there's only the single 

consonant ( r ) following so in this case, yes, we do need to lengthen that 

a to an ā if we want our root syllable to become heavy.
