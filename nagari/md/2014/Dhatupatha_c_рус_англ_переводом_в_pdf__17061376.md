## 3. Mandala Pati (Владислав) — 2014-01-14 02:44:21 · 📎 3

Сохранил ваш файл как ПДФ. Есть простая бесплатная программа для этого: 
doPDF. Хотя даже в ворде сейчас есть опция "сохранить как" и выбрать 
расширение ПДФ.

В прицепе также дхату-патха Шрилы Дживы Госвами, традиционная и по алфавиту.

Также советую вам посмотреть книгу "Dhatu-ratnakara" of Muni Lavanya 
Vijaya. Parimala Publications. Там в конце первого тома перевод на англ. 
для почти 2000 дхату.
