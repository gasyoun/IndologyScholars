## 5. Serge A — 2015-11-17 14:20:08

Регламент юникода предлагает для кружка использовать комбайн 0325. Этим же 
способом можно и ударение прилепить. Правда, тут надо, чтобы и разработчики 
шрифта знали об этих вариантах букв. В противном случае дикритика может 
криво цепляться, а то и вовсе квадратиком.

r + 0325 = r̥ ; 

r + 0325 + 0301 = ŕ̥ ;

r + 0325 + 0304 = r̥̄ ; 

r + 0325 + 0304 + 0301 = r̥̄́ ;

l + 0325 = l̥ ; 

l + 0325 + 0301 = ĺ̥ ( l + 0301 + 0325 = ĺ̥ ) ; 

l + 0325 + 0304 + = l̥̄ ( l + 0304 + 0325 = l̥̄ ) ; 

( l + 0304 + 0301 + 0325 = l̥̄́ ).
(В версии шрифта Cambria у меня на компе для l кружок надо втыкать в конце, 
иначе не клеится. Не знаю, может, в других версиях по-другому. ) 

Стандарт ISO 15919, регламентирующий кружочки в индийской диакритике, был 
утверждён уже 15 лет как. За это время символы так и не внесены в набор 
стандартных юникодовских знаков. Хотя примечание на их счёт дано. Надежд на 
изменение политической ситуации нет. Юникодовцы сейчас очень скупердяйски 
распоряжаются местом для символов. На предложение включить гласные с 
кружками в стандарт в 2013 было отказано. Так что извольте колупаться с 
комбайнами, дорогие санскритологи.

*C.4.2 Proposal to encode Latin letters for the transliteration of Indic 
vocalic letters [Pandey, L2/13-204 
<http://www.unicode.org/cgi-bin/GetMatchingDocs.pl?L2/13-204>] * 

*[137-A2 <http://www.unicode.org/cgi-bin/GetL2Ref.pl?137-A2>] Action item 
for* Rick McGowan: Respond to the author of L2/13-204 
<http://www.unicode.org/cgi-bin/GetMatchingDocs.pl?L2/13-204> that *UTC 
declines to encode these*; they are already representable in the standard.
