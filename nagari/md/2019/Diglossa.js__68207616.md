## 1. Michael Bykov — 2019-01-25 02:14:53

http://ru.diglossa.org/diglossa.js - простое приложение для работы с
параллельными текстами. Удобно для переводчиков и внимательных
читателей. Не сложнее FB2-Reader, но для параллельных текстов.
Полнотекстовый поиск, интеграция с Морфеем. Пока только первая часть,
десктоп. Серверная часть будет вскорости, я надеюсь. Там же скринкаст
и ссылки на код и пакеты для Win, MacOS, Linux. Лицензия GNU GPL.
Замечания и предложения направляйте, пожалуйста, в группу
