# IAST modification of standart layout for *nix systems.

> 4 сообщений · 3 участников · 2013-03-11 — 2013-03-11

## 1. śrīdṛṣṭvā — 2013-03-11 13:04:16

Быть может кому-то пригодиться моя модификация раскладки клавиатуры, для 
быстрого набора текста в IAST, для меня этот вариант значительно быстрее и 
удобнее чем ITRANS со своими шифрами типа RR^i. Сразу стоит заметить что я 
не знаю возможно ли такое сделать для Win, не уверен что сработает для Mac, 
проверял и тестировал только на линуксе. А на последнем как всегда – не 
надо много волшебства (лишь чуть-чуть), чтобы сотворить поистине 
невероятные вещи, словно легким махом дирижер заводит оркестр. Итак, нам 
нужен *файлик /usr/share/X11/xkb/symbols/us* открываем его с правами 
суперпользователя и подменяем там первый блок, отличаться он должен только 
символами записанными в юникоде типа U0xxx.

default
partial alphanumeric_keys modifier_keys 
xkb_symbols "basic" {

    name[Group1]= "USA";

    // Alphanumeric section
    key <TLDE> {    [     grave,    asciitilde    ]    };
    key <AE01> {    [      1,    exclam         ]    };
    key <AE02> {    [      2,    at        ]    };
    key <AE03> {    [      3,    numbersign    ]    };
    key <AE04> {    [      4,    dollar        ]    };
    key <AE05> {    [      5,    percent        ]    };
    key <AE06> {    [      6,    asciicircum    ]    };
    key <AE07> {    [      7,    ampersand    ]    };
    key <AE08> {    [      8,    asterisk    ]    };
    key <AE09> {    [      9,    parenleft    ]    };
    key <AE10> {    [      0,    parenright    ]    };
    key <AE11> {    [     minus,    underscore,    U0304,    U0306    ]    
};
    key <AE12> {    [     equal,    plus        ]    };

    key <AD01> {    [      q,    Q         ]    };
    key <AD02> {    [      w,    W        ]    };
    key <AD03> {    [      e,    E,    U0113,    U0112    ]    };
    key <AD04> {    [      r,    R,    U1E5B,    U1E5D    ]    };
    key <AD05> {    [      t,    T,    U1E6D,    U1E6C    ]    };
    key <AD06> {    [      y,    Y        ]    };
    key <AD07> {    [      u,    U,    U016B,    U016A    ]    };
    key <AD08> {    [      i,    I,    U012B,    U012A    ]    };
    key <AD09> {    [      o,    O,    U014D,    U014C    ]    };
    key <AD10> {    [      p,    P        ]    };
    key <AD11> {    [ bracketleft,    braceleft    ]    };
    key <AD12> {    [ bracketright,    braceright    ]    };

    key <AC01> {    [      a,    A,    U0101,    U0100    ]    };
    key <AC02> {    [      s,    S,    U1E63,    U1E62    ]    };
    key <AC03> {    [      d,    D,    U1E0D,    U1E0C    ]    };
    key <AC04> {    [      f,    F        ]    };
    key <AC05> {    [      g,    G,    U1E45,    U1E44    ]    };
    key <AC06> {    [      h,    H,    U1E25,    U1E24    ]    };
    key <AC07> {    [      j,    J,    U00F1,    U00D1    ]    };
    key <AC08> {    [      k,    K        ]    };
    key <AC09> {    [      l,    L,    U1E37,    U1E39    ]    };
    key <AC10> {    [ semicolon,    colon        ]    };
    key <AC11> {    [ apostrophe,    quotedbl,    U093D    ]    };

    key <AB01> {    [      z,    Z         ]    };
    key <AB02> {    [      x,    X        ]    };
    key <AB03> {    [      c,    C,    U015B,    U015A    ]    };
    key <AB04> {    [      v,    V        ]    };
    key <AB05> {    [      b,    B        ]    };
    key <AB06> {    [      n,    N,    U1E47,    U1E46    ]    };
    key <AB07> {    [      m,    M,    U1E43,    U1E42    ]    };
    key <AB08> {    [     comma,    less,    U0964    ]    };
    key <AB09> {    [    period,    greater,    U0965    ]    };
    key <AB10> {    [     slash,    question,    U0950    ]    };

    key <BKSL> {    [ backslash,         bar    ]    };
    // End alphanumeric section
};



Подменив этот блок текста, осталось только вскормить его системе, для чего 
мы открываем System Settings->Keyboard Layout->Layouts->Options, там 
выбираем "Key to choose 3rd level", можно клавишу Win, можно правый Alt, 
как вам удобнее, я привык к R.Alt. Если клавиша уже выбрана, то мы снимаем 
и отмечаем эту галочку лишь для того, чтобы вскормить новые Unicode 
символы, которые указаны в файлике /usr/share/X11/xkb/symbols/us
Теперь, комментарии и пояснения, что есть что:

   <Key name> { [  symbol, Shift+symbol, R.Alt+symb,Shift+R.Alt+symb ] };
    key <AE11> {    [     minus,    underscore,    U0304,    U0306    ]   
 };
На клавише "минус/подчеркивание" будут надстрочники āă, это на самом деле 
не имеет отношения к IAST, я использовал для латыни.
    key <AD03> {    [      e,    E,    U0113,    U0112    ]    };
    key <AD04> {    [      r,    R,    U1E5B,    U1E5D    ]    };
    key <AD05> {    [      t,    T,    U1E6D,    U1E6C    ]    };
Символы eEēĒ, rRṛṝ (тут заглавные символы пришлось опустить), tTṭṬ
    key <AD07> {    [      u,    U,    U016B,    U016A    ]    };
    key <AD08> {    [      i,    I,    U012B,    U012A    ]    };
    key <AD09> {    [      o,    O,    U014D,    U014C    ]    };
Символы uUūŪ, iIīĪ, oOōŌ.
    key <AC01> {    [      a,    A,    U0101,    U0100    ]    };
    key <AC02> {    [      s,    S,    U1E63,    U1E62    ]    };
    key <AC03> {    [      d,    D,    U1E0D,    U1E0C    ]    };
Символы aAāĀ, sSṣṢ, dDḍḌ, здесь есть спорный момент как использовать 
клавишу "s", я использую для прописной и заглавной ṣ(как в слове kṛṣṇa), 
быть может кто-то сочтет безсмысленным использование символа Ṣ и предпочтет 
поставить туда символ ś.
    key <AC05> {    [      g,    G,    U1E45,    U1E44    ]    };
    key <AC06> {    [      h,    H,    U1E25,    U1E24    ]    };
    key <AC07> {    [      j,    J,    U00F1,    U00D1    ]    };
Символы gGṅṄ, hHḥḤ, jJñÑ, быть может у кого-то это и вызовет смущение, но я 
нашел этот вариант наиболее подходящим для описания 6 различных звуков 
ṅñṇnmṃ, поскольку двух клавиш оным недостаточно. Итак вспоминаем звуковой 
ряд и нужный вариант n будет как раз дополнением клавиши звонкой согласной.
    key <AC09> {    [      l,    L,    U1E37,    U1E39    ]    };
    key <AC10> {    [ semicolon,    colon        ]    };
    key <AC11> {    [ apostrophe,    quotedbl,    U093D    ]    };
Символы lLḷḹ, вакантная для спецсимволов клавиша ";", а на апостроф я 
повесил ऽ ануграху(U093D), использование которой всегда однозначно, в 
отличии от апострофа.
    key <AB03> {    [      c,    C,    U015B,    U015A    ]    };
    key <AB06> {    [      n,    N,    U1E47,    U1E46    ]    };
    key <AB07> {    [      m,    M,    U1E43,    U1E42    ]    };
Символы cCśŚ, nNṇṆ, mMṃṂ, поскольку символ ś по звукообразованию находится 
в ряду ca,cha, то я его повесил на эту клавишу. Можно перенести на клавишу 
s, если это покажется логичнее, но в данной раскладке нет необходимости 
прижимать Shift+R.Alt одновременно (кроме ṝ и ḹ ). Клавишу n дополняют 
ретрофлексный звук ṇ, анусвара же на клавише m. Вроде всё, весь алфавит 
изложен. Теперь отдадим честь разделителям деванагари:
    key <AB08> {    [     comma,    less,    U0964    ]    };
    key <AB09> {    [    period,    greater,    U0965    ]    };
    key <AB10> {    [     slash,    question,    U0950    ]    };
Символы ,<। и .>॥ тут вроде и всё, но мы бы забыли главное, если бы не 
повесили на клавишу / всеми любимый ॐ
ॐ namaḥ śivāya ॥

После этого можно воспользоваться 
http://epandit.shrish.in/tools/IAST-DV-IAST/ и получить
ॐ नमः शिवाय ॥

Так заканчивается повествование "IAST modification of standart layout for 
*nix systems".

## 4. śrīdṛṣṭvā — 2013-03-11 16:48:47

могу печатать все без исключения символы древнерусской азбуки. Находил 
также глаголицу, но то уже вовсе не практично. 

С деванагари проблем нет, да и не было. Кстати, LibreOffice я всячески 
избегаю, для набора текста у меня есть святой gedit. Можно выбрать язык 
Indian и будет полноценная раскладка деванагари. Вот, кстати, наглядный
