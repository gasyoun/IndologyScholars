## 4. Serge A — 2013-07-09 13:58:53

Думаю, это многим может быть интересно. На сегодняшний день на сайте 
Пенсильванского Университета выложены изображения 216 санскритских 
манускриптов. Первый из них датируется 1572 годом, последний - 1895. По 
умолчанию грузятся уменьшенные картинки 1/8 размера, но можно выбрать 
полноразмерный показ и рассмотреть все детали.

http://dla.library.upenn.edu/dla/medren/search.html?fq=collection_facet%3A%22Indic%20Manuscripts%22%20AND%20facsimile_facet%3A%22Yes%22&
