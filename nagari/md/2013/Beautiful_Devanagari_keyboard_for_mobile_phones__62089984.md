Description

Towards the unity - typing in Devanāgarī for everybody!

Flawless, comfortable and enjoyable typing of texts on a mobile phone using 
the Devanāgarī script!

Tanontech Devanāgarī keyboard is an Indic IME which allows you to type 
texts, messages on social networks or compose emails using Devanāgarī 
script on your Android phone. If you can read हिंदी correctly on your 
phone, then you may install and use the Tanontech Devanāgarī keyboard, 
otherwise your phone may not support Devanāgarī script.

You set the Tanontech Devanāgarī keyboard as default input method/IME on 
Android 4.x and newer versions as follows:
Open Settings -> Language & Input, under “Keyboards and input methods” 
section, check "Tanontech Devanāgarī keyboard", then click Default and 
select “Tanontech Devanāgarī keyboard” in the “Choose input method” dialog.

Please NOTE that before Android 4.0, Google did not provide official 
Devanāgarī font support. Please make sure that your manufacturer does 
provide an additional Devanāgarī font in your phone in this case. Your 
device may need different steps for setting up the Tanontech Devanāgarī 
keyboard - please check the device’s user guide/manual for details.

The control buttons on the Tanontech Devanāgarī keyboard do have the 
following functions:

- short click over the vertical keyboard shuffle button switches the 
keyboard layout between Devanāgarī and the quick shuffle keyboard. The 
quick shuffle keyboard layout is set up within the keyboard preferences.

- long click over the vertical shuffle button invokes the general options 
dialog allowing for activation the additional keyboards and for changing 
the keyboard preferences.

- short click over the horizontal tracking keyboard button switches between 
the regular and the extended layout of the current keyboard.

- the shift button has the same function as usual on a hardware keyboard.

The Tanontech Devanāgarī keyboard supports two most usable keyboard layouts 
for Devanāgarī script: phonetic and INSCRIPT. Thus the experienced users of 
those layouts will find the most characters on the same places - no 
learning required and you start type texts in Devanāgarī immediately.

The Tanontech Devanāgarī keyboard additionally provides QWERTY (English) 
and cyrillic (Russian) keyboards which can be set up as a quick shuffle 
keyboards in the preferences for fast switching between them and the 
Devanāgarī script.

Due to the security reasons and for saving your privacy we don't track any 
typing activities of the user, thus we make no suggestions and no 
predictions for what the user is going to type.
