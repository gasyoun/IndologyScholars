*Walter Slaje:* Georg Bühlers Leitfaden für den Elementarkursus des 

Sanskrit. Schlüssel zu den Übungsstücken. Wichtrach 1986. *(M.G.)*



 



Corrigenda



I     läuft ... fällt : lauft ... fallt



II    gedenken wir : gedenken sie



IV    *dahati vṛkṣān *: *vṛkṣān dahati*



V     dem Lehrer : dem Lehrer (/ für den Lehrer)



*ā ... śikharebhyo *: *śikharebhya ā*



VII   aus dem Dorf : aus dem Haus



      *balau *: *bālau*



VIII  Hymnen : zwei Hymnen



IX    *prabhūtā bhikṣā *: *prabhūtāṃ bhikṣāṃ*



      *kṛṣṇebhyo ’śvebhyo *: *kṛṣṇābhyām aśvābhyām ava*°



XI    *kopena* : *kopena* (/ *kopād*)



XIV   *ānayateti* : *ānayatam iti*



      *ādiśyatām* : *ādiśyetām*



XVII  *tad* : *tat*



      °*opanīyeyātām* (/ *upanīyetām*) :  °*opanīyeyātām*



XIX   Kühne : Kühe



*māṃ ... tvāṃ ... anyaṃ bhrātaraṃ* : *mahyam / me ... tubhyaṃ / te ... 

anyasmai bhrātre*



XX    *sarve* : *sarvāḥ*



XXI   dem Lehrer nicht nähern : beim Lehrer nicht bleiben



XXV   *devānām* : *devānāṃ*



XXVI  *dvipādāṃ catuṣpādāṃ* : *dvipadāṃ catuṣpadāṃ*



XXVII Hier/da(s) bin ich: Ich bin (/ heiße) N. N.



      *rugṇebhas* : *rugṇebhyas*



XXIX  Nachdem sie ... geopfert hatten : Nachdem er ... geopfert hatte



XXXI  *trīṇi śatāni* : *trīṇi sahasrāṇi trīṇi śatāni*



XXXII *draghiṣṭhāḥ* : *drāghiṣṭhāḥ*



      *laghīyaṃ* : *laghīyaḥ*



XXXIV wohnt : wohnte



er ihn mit einem ... gespannten Pfeil :  er, dessen Pfeil bis ... gespannt 

war, ihn



°*karmakṛtās* : °*karmakṛtas*



*ṣaḍḍinaṃ* : *ṣaḍdinaṃ*



*arthayati* : *arthayate*



XXXV  *rājasis* : *rājāsis*



XXXVI       Wer von einem Brahmanen ... : Wer [einem] mit dem *brahman* die 

Ohren füllt, dem darf man niemals, indem man ihn ...



XXXIX schädigen : töten



*api* : *apy*



      *vānyamatenauṣṭhau* :  *vānyamatenoṣṭhau*



      *netrebhyo ’śrūny/netrebhyām āśrūny* : *netrābhyām āśrūṇy*



      *dvipādāṃ catuṣpādāṃ* : *dvipadāṃ catuṣpadāṃ*



XLI   *daivam* : *daiva*



XLII  (all) das, was er tut : (all) das, woran er denkt, was er tut



      *kṣātram *: *kṣātra*



      *bunaktu* : *bhunaktu*



XLIV  *nirneṣyanti* : *nirṇeṣyanti*



XLV   *pratyaikṣiṣya iti* : *pratyaikṣiṣyathā iti*



XLVI  *janā* : *janāḥ*



XLVII *uttaraṇamārgāya* : *uttaraṇamārgāya* (/ *uttaraṇamārge*)
