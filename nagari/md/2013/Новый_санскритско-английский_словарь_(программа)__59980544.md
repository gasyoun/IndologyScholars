Данных берутся из книг, которые я имею. В основном это сканы. Всё 
набирается в ворде (большую часть через функцию замены текста) латиницей, 
потом конвертируется в деванагари. Дело довольно не сложное, но поскольку 
всевозможных форм ОЧЕНЬ много, то конца-края этому пока не видно. Так 
например недавно у меня появилась книга, которая кроме основных форм 
(karoti, paṭhati) даёт ещё и kṛt-формы (dṛṣtvā, tyaktvā) многих видов для 
всех дхату. Ещё у меня есть скан пятитомника, где приводятся формы 
дезератива, интенсива, кармани-прайоги, имперсонального пассива. То есть 
набирать есть что. Если у кого есть желание внести свой посильный вклад, 
милости просим.
