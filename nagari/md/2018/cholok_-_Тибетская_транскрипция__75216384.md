## 1. Michael Bykov — 2018-12-27 00:22:58

Салют, может быть интересно:



cholok - https://github.com/mbykov/cholok



ཆོས་ཀློག་ - cʰö.loḳʰ - чтение вслух, речитация



cholok - скрипт для фонетической транскрипции Тибетского языка.



Например, (кумулятивно, результат - последний элемент):

གད་ - ḳʰa-ṭʰa-ḳʰë

རྗེས་འཇུག་ - ṛa-jatak-ja-ḋeŋ̣bu-je-sa-je.ạo-nja-ŝapkyu-nju-ḳʰa-njuḳʰ

གསུངས་ - ḳʰao-sa-ŝapkyu-su-ŋ̣a-sa-suŋ̣



В командной строке:



$ sudo npm -g install cholok-cli

$ cholok -c ཆོས་ཀློག་

=> cʰa-naro-cʰo-sa-cʰö.ka-ḷatak-la-naro-lo-ḳʰa-loḳʰ

$ cholok ཆོས་ཀློག་

=> cʰö.loḳʰ





По материалам лекций геше Майкла Роуча -

https://www.youtube.com/playlist?list=PL1KVm5jgTljTatThw2YLw7nrf05XYBcZV



Лицензия GNU GPL



Но, увы, санскритский текст в Тибетском (там свои правила), в этой

версии пока не обрабатывается, сделаю позже
