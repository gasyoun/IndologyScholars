Термина "shareware" применяется для обозначения программного
обеспечения, которое предоставляет пользователю некоторое время для
тестирования, по истечении которого пользователь обязан заплатить за
лицензию для дальнейшего использования (активация). Однако в данном
случае автор действительно оставил право принимать решение о
регистрации самому пользователю. Назовём эту ситуацию "условно
бесплатно". Наверное, нет смысла дальше тратить время на эту дискуссию
