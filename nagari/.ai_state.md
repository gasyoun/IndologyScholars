гуглгруппы». Built in worktree `IndologyScholars-nagari` (branch
`nagari-20yr-archive`) — main tree is a hard-block worktree repo.

## 🧠 Dev Notes & Hypotheses
- Source order is newest-first; parse boundaries streamed by `^From ` (mailbox not
  used) so one malformed message can't abort — 0 parse errors on 18 729.
- Threading uses `X-GM-THRID` (Gmail thread id) → 2 928 threads; reply edges from
  `In-Reply-To` resolve 13 036 links.
- Key finding: message volume peaked 2015 (2 593), but thread COUNT keeps rising
  into 2025 (293) — long debates gave way to many short Q&A threads.
- IAST top terms are the traditional commentary apparatus (anvaya, pratipadārtha,
  padavibhāga, tātparya) — fingerprints the reading-group method.
- 367 book-like files (294 PDF, 216 MB): Knauer, Bühler, Śaṅkara-bhāṣyas, etc.
- Browser-pane screenshots time out on the SVG-heavy page; verified via JS DOM
