## 🧠 Dev Notes & Hypotheses (Bugs, ideas, context)
- **Как генерируются страницы:** функции `generate_sociology_page()` и
  `generate_gatekeeping_page()` в `generate_publication_pages.py` (вставлены перед
  `generate_classification_criteria_page`, вызываются в `main()` после неё). Общий стиль —
  константа `ARTICLE_STYLE` (extra_head). Обёртка — `page_shell(title, desc, canonical,
  body, structured_data, extra_head=...)` из `publication_helpers.py`; шаблон
  `templates/base.html` даёт nav+footer и грузит `assets/styles.css`.
- **Две системы CSS-токенов (важно!):** `styles.css` использует `--text/--accent/--border/
  --muted/--soft/--panel`; старый `index.css` использовал `--text-primary/--accent-primary/
  --border-color`. Генерируемые страницы грузят ТОЛЬКО `styles.css` — писать инлайн-CSS
  на токенах styles.css, иначе текст «исчезнет».
- **Данные под утверждения:**
  - таблицы поколений → `analytics_output/senior_absence_audit.csv` (когорты
    `absent_after_2022` и `absent_in_2026`; сорт = (-talks_before_threshold, display_name));
    генерится в `generate_analytics.py::generate_senior_absence_audit`.
  - сетевая дисциплина → `analytics_output/network_robustness_checks.csv` (колонки
    `forbidden_inference`, `required_sensitivity_check`, модели NET01..NETxx) — ЗОЛОТО
    для цели «защищаемость», брать формулировки оттуда.
  - граф → `network_nodes.csv` / `network_edges.csv` / `network_data.json`.
  - фигуры рисует `scratch/generate_sociology_plots.py`.
- **Сборка/проверка (обязательно перед коммитом):**
  `python generate_publication_pages.py` → `python validate_publication.py` →
  `python -m pytest`. Быстрая проверка только этих 2 функций без всего пайплайна:
  `python -c "import generate_publication_pages as g; g.generate_sociology_page(); g.generate_gatekeeping_page()"`.
- **Git-workflow:** репозиторий работает напрямую в `main`, CI авторебилдит и деплоит
  Pages. Полный билд обычно меняет немного производных файлов (в этой сессии — 7).
  Перед пушем: `git fetch origin main` → `git rebase origin/main` → `git push`.
  `findings/visualisations.html` даёт недетерминированный шум (переупорядочение ARC_DATA) —
  это свойство билда, не наша правка.
- Память Claude по проекту: см. ключи `visualisations-are-generated`,
  `indology-git-push-workflow`, `philology-research-agents-module`,
  `parser-slippage-and-id-churn`.
