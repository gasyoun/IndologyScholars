**Назначение.** Рабочий список предметных рубрик для отслеживания книг-кандидатов на выкачивание и выкладку в Обществе ревнителей санскрита (см. VK-пост 2020: «Не хватает списка книг-кандидатов для выкачивания из Иностранки и некому выкладывать то, что уже выкачано»).

**Важно о словаре рубрик.** Список «Предметная рубрика» в [расширенном поиске](https://catalog.libfl.ru/Search/Advanced) обрезан: ровно 200 значений по алфавиту, и **ни одной индийской/санскритской рубрики в нём нет** (даже «Языкознание • Диссертации» — исключение). Полный словарь извлекается из фасетов результатов поиска (`topic_facet`), фасетный словарь — через [FacetList](https://catalog.libfl.ru/Search/FacetList?lookfor=%D1%81%D0%B0%D0%BD%D1%81%D0%BA%D1%80%D0%B8%D1%82&type=Subject&facet=topic_facet). Все рубрики ниже подтверждены живым поиском.

**Как читать ссылки.**
- **Фильтр** — весь фонд по рубрике (пустой запрос + `filter[]=topic_facet:"…"`);
- **Новые** — то же с `arrivalrange[]=NewArrivals`, в формате исходного примера; **окно дат пустое** — при желании добавьте `NewArrivalsfrom=` / `NewArrivalsto=` (ГГГГ-ММ-ДД), например `&NewArrivalsfrom=2026-08-01`.

**Примеры** отобраны по релевантности (верхние результаты фильтра), 1–2 на рубрику. Пересечения примеров между рубриками естественны (одна книга может стоять в нескольких рубриках).

1. **Найти новые/новые рубрики:** [FacetList по запросу](https://catalog.libfl.ru/Search/FacetList?lookfor=%D0%B8%D0%BD%D0%B4%D0%B8%D1%8F&type=Subject&facet=topic_facet) (`type=Subject`, `facet=topic_facet`, страницы `facetpage=2,3…`) — словарь обновляется библиотекой, проверять раз в квартал.
2. **Проверить актуальность примеров:** открыть ссылку «фильтр» первой колонки, верхние 1–2 результата = примеры (критерий: релевантность сверху).
3. **Ссылки «новые»:** окно дат пустое (формат исходного примера); для точечного мониторинга добавить `&NewArrivalsfrom=ГГГГ-ММ-ДД`.
4. **Не полагаться на список в расширенном поиске** — он обрезан (200 рубрик) и не содержит индийских/санскритских значений.
