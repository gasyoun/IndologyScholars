### `scrape_common.py` (новый, общий модуль)
Устранил тройное дублирование HTTP/нормализации. Содержит:
- `http_get()` — retry + экспоненциальный backoff + дисковый кэш (линк из РФ
  роняет SSL-handshake — одной попытки мало);
- `atomic_write_json()` — запись через temp + `os.replace` (см. ниже про
  разрушительный «полный цикл»);
- `normalize_name()` — единая нормализация (ё→е, регистр, пробелы).

**Режим `--wide`** добавлен: помимо `Russian Indologists`, сканирует

## 2026-06-05 — Технические ограничения

### Блокировка ru.wikipedia.org/api.php
- **Симптом:** SSL handshake timeout на `/w/api.php`
- **Причина:** Роскомнадзор, блокировка API-эндпоинтов
- **Обнаружено:** при попытке повторного запуска `expand_wikipedia_indologists.py`
- **Обход:** HTML-поиск через `w/index.php?search=` + парсинг text-версий категорий
- **Что не работает:** `action=query`, `action=parse`, `action=wbgetentities` — все на ru-домене

### Нестабильность Wikidata API
- **Симптом:** попеременные 502 Bad Gateway / transport error / success
- **Причина:** перегрузка публичного endpoint на стороне Wikimedia
- **Что работает стабильно:** `Special:EntityData/Qxxx.json` (REST, не API)
- **Что нестабильно:** `w/api.php`, `query.wikidata.org/sparql`

### JS-рендеринг институциональных сайтов
- **Симптом:** HTML содержит 79 КБ шаблона, контент загружается через JS/AJAX
- **Затронуты:** `ivran.ru/sotrudniki`, `ivran.ru/persons/*`, `rggu.ru`, `hse.ru`
- **Обход:** использование конференционной базы как прокси для аффилиаций
- **Документировано:** см. roadmap.md, раздел «Этап 3»
