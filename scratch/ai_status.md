## Текущие ограничения

### 1. Блокировка `ru.wikipedia.org/api.php`
- **Симптом:** SSL handshake timeout
- **Причина:** Роскомнадзор
- **Влияние:** невозможен `action=query`, `action=parse`, `action=categorymembers`
- **Обход:** HTML-поиск через `w/index.php?search=`, text-версии категорий (✅ реализовано)
- **Не протестировано:** `ru.m.wikipedia.org/w/api.php`, `en.wikipedia.org` + `langlinks`

### 2. Нестабильный Wikidata API
- **Симптом:** попеременные 502 / transport error / OK
- **Влияние:** невозможен надежный SPARQL, нестабильный `wbgetentities`
- **Что работает:** `Special:EntityData/Qxxx.json` (REST) — ✅ стабильный
- **Стратегия:** использовать только REST, батчинг по 5 Q-ID

### 3. JS-рендеринг институциональных сайтов
- **Симптом:** `ivran.ru/persons/*` возвращает шаблон без контента (79 КБ)
- **Влияние:** невозможно извлечь должность/отдел/био через HTTP GET
- **Обход:** конференционная база как прокси для аффилиаций (✅ реализовано)
- **Перспектива:** поиск JSON API (Drupal), playwright для headless Chrome
